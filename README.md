Nusantara Sky Courier — an original island-hopping courier flight game. Take off from a jungle airstrip, thread gold rings between the islands of eastern Indonesia, drop the mail on target, and bring the plane home onto a short mountain strip. Three missions (Island Hop, Mail Run, Storm Rescue), free flight, chase and cockpit cameras with lit instruments, wind, fuel, flaps, gear, stall and smooth-landing scoring. Keyboard + mouse, no install, no network — plain static files.

## Run it

```sh
python3 -m http.server 8000 --directory game
# open http://localhost:8000 in a desktop browser
```
